本发行版由 Dingtaiqi 独立维护，包含 K60 Pro（socrates）与 K90 Pro Max（myron）的 Skyward REC 镜像。

### 本次更新

- 多用户解密分别记录失败：副用户缺少 spblob 或密钥时，不再阻断主用户；完整 data 备份仍要求全部用户已解密。
- REC 内置更新切换到本仓库，提供国内 GitHub 镜像与直连回退；更新清单验证 Ed25519 签名，镜像 ZIP 校验 SHA-256。
- 新增标准目录形式的 KernelSU／Magisk 模块管理：启用、禁用、下次启动卸载、取消卸载及应急禁用全部模块。
- 新增当前槽位 AVB 状态查看与禁用入口：写入前先备份原始 vbmeta 并校验；补充 Xiaomi orange 启动状态识别。
- 支持按具体分区选择备份／恢复，分组展示并保留独立选择；修复恢复写入后块设备只读标志的恢复。
- 统一模块、AVB、备份／恢复页面的卡片间距、信息层级和操作入口；提供两机实际分辨率与密度的浅色、深色预览。

| --- | --- | --- |
| K60 Pro / socrates | OS3.0.304.0.WMKCNXM，Android 16 | 采用已在测试机 Android 17 系统上验证的解密兼容配置，KeyMint 系统补丁日期下限为 2026-09-01；文件名含 decrypt20260901 |

### 验证范围与更新说明

- 两机完整构建、回归检查和 UI 渲染通过。K60 新增模块操作与单分区备份已完成实机验证；界面最后一轮调整已检查渲染，尚未重新实机验收。
- K90 已用本次发行的程序在原 REC 中临时运行，显示、触摸、解密、测试模块四项操作、单分区备份校验、恢复选择、AVB 状态与联网检查更新通过；原模块及五个受保护分区保持不变。此测试未刷入完整 0.2.2 镜像，不作为该镜像原生启动验收。
- K90 本轮测试中出现一次亮屏静置时自行重启，原因尚未定位，稳定性验收仍未通过。随后未解密、未联网的八分钟亮屏待机未复现；没有取得能证明内核 panic 或 watchdog 故障的日志，不将这次未复现视为已修复。
- AVB 实际修改及新增分区恢复流程尚未在这两台测试机上实刷验证，不将界面可用等同于写入验收。
- 含旧更新地址的 REC 需要先手动安装带本仓库签名更新渠道的版本，旧地址不会远程改变。
- 下载附件是 ZIP 压缩的完整 REC 分区镜像。SHA256SUMS 校验 ZIP，解压后的 IMG 摘要不同属于正常情况。请严格区分 socrates 和 myron；此发行版不包含 boot、init_boot 或 vendor_boot 刷写包。

附件同时提供签名 updates.json、ZIP 校验表及所附静态 Bash 的对应源码。
